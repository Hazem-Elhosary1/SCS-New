# وثيقة متطلبات الأعمال — Smart Clinic OS

## المجلّد ٠ · الأساس المشترك

**الإصدار ٠٫٧ — ١٠ أكتوبر ٢٠٢٦** · المالك: Heta Systems · الحالة: مسودّة للمراجعة

هذا المجلّد يحمل ما يشترك فيه النظامان: النطاق، والفاعلون، والباقات والحدود، والهويّة والدخول، والمال بين الأطراف، والتكاملات، والمتطلّبات غير الوظيفيّة، والامتثال، والمصطلحات. المجلّد ١ للوحة العيادة وواجهات المريض، والمجلّد ٢ للوحة المشغّلين، وكلاهما يحيل إلى هذا ولا يكرّره.

## ٢ · المنتج ونطاقه

**Smart Clinic OS** منصّة سحابيّة متعدّدة العيادات، تبيعها Heta Systems اشتراكًا شهريًّا أو سنويًّا لعيادات مصر.

| المكوّن | لمن | ما يفعله |
|---|---|---|
| لوحة العيادة | فريق العيادة | الحجوزات، المرضى والكشف، الفواتير والتحصيل، الصندوق الوارد، التقارير، الإدارة، الإعدادات |
| واجهات المريض | المريض | صفحة الحجز العامّة، الدفع، الدور، الكشف عن بُعد، تقييم الزيارة، مواعيدي |
| لوحة المشغّلين | فريق Heta | العيادات، الباقات، فوترة الاشتراكات، التذاكر، التنبيهات، الأمان، إعدادات المنصّة |
| المنصّة | — | واجهة برمجيّة واحدة وقاعدة بيانات واحدة معزولة لكلّ عيادة |

| # | المتطلَّب | الحالة |
|---|---|---|
| SH-001 | السوق مصر، والعملة الجنيه المصريّ، والمنطقة الزمنيّة القاهرة | مطلوب |
| SH-002 | الواجهات كلّها بالعربيّة والإنجليزيّة، ولكلّ مستخدم لغته، والعربيّة من اليمين إلى اليسار | مطلوب |
| SH-003 | لكلّ عيادة عنوانان: للفريق `<العيادة>.app.smartclinicos.com` وللمرضى `<العيادة>.smartclinicos.com`، ويضبط الاسمَ فريقُ الدعم | مطلوب |
| SH-004 | بيانات كلّ عيادة معزولة عن غيرها على مستوى الصفّ في قاعدة البيانات | مطلوب |
| SH-005 | لا وحدة في لوحة العيادة بلا ما يقابلها في لوحة المشغّلين أو تدفّق كامل ينتهي | قاعدة |

**خارج النطاق بقرارات سابقة:** تطبيق موبايل للمريض · الرواتب · الصيدليّة · نقاط الولاء وبطاقات الهدايا · مطالبات التأمين ونماذجها · حظر العناوين من جهة العيادة.

**لاحقًا:** المخزون والمستهلكات · العلامة التجاريّة المخصَّصة · ماسنجر وإنستغرام · السحب التلقائيّ من البطاقة · الفاتورة والإيصال الإلكترونيّ · عيادات خارج مصر.
